# Smart Restaurant Management System

## Team Name
Team Innovators

## Project Overview
Smart Restaurant Management System is a full-stack SaaS platform designed to improve restaurant operations. It streamlines ordering, reservations, inventory management, customer communication, and restaurant analytics while enhancing the dining experience through intelligent features.

---

## Features

### Customer
- User Registration & Login
- Google Authentication
- Digital Menu
- Live Food Availability
- Table Reservation
- Order Tracking

### Restaurant Management
- Order Dashboard
- Table Management
- Inventory Management
- Sales Analytics
- Customer Management

### AI Features
- AI Wait Time Prediction
- Personalized Food Recommendations
- Smart Notifications

---

## Installation

1. Clone the repository

```bash
git clone https://github.com/yourusername/restaurant-management.git
```

2. Install dependencies

```bash
npm install
```

3. Run the backend

```bash
npm run server
```

4. Run the frontend

```bash
npm start
```
